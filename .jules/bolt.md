## 2025-02-23 - Optimize geographical distance calculation
**Learning:** Computing geographic distances over a large dataset using the Haversine formula inside a loop can cause high CPU usage and function call overhead, especially if constant values are recalculated on each iteration.
**Action:** When calculating geographic distances iteratively against a static point (like a user's location), hoist the invariant mathematical conversions (such as converting to radians and trigonometric values like `Math.cos()`) outside the loop. Inline small mathematical formulas directly into the loop to reduce function call overhead.
