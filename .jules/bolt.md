## 2025-02-18 - Batch DOM Appends with DocumentFragment
**Learning:** Appending hundreds of nodes individually to the DOM inside loops (like generating station lists) forces synchronous reflows on each append, causing a significant layout thrashing bottleneck.
**Action:** When rendering long lists (like `stationsListEl` or `djStationList`), append newly created elements to a `DocumentFragment` first. Append the fragment to the DOM once the loop finishes to limit DOM operations and improve render performance.

## 2025-02-18 - Caching getComputedStyle properties
**Learning:** Calling `getComputedStyle` synchronously inside a high-frequency `requestAnimationFrame` loop (like rendering an audio visualizer or globe points) causes severe style recalculation layout thrashing, which is a major performance bottleneck for smooth animations.
**Action:** Extract the values generated by `getComputedStyle` once during app startup or theme change, cache them in a global state variable, and use these cached values within animation and rendering loops.
